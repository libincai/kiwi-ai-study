# KIWI 爱AI Study — homepage refresh

This package updates the existing website to closely match the approved homepage mockup.

## Files
- `index.html` — updated homepage structure and hero accent
- `styles.css` — rebuilt desktop layout and responsive tablet/mobile styles
- `assets/` — existing logo, hero, book covers, and social-channel graphics
- `privacy.html`, `terms.html`, and the verification TXT file — preserved from the original project

## Replace your local repository files
1. Make a backup of your current `kiwi-ai-study` folder.
2. Extract this ZIP directly **into the root of your local `kiwi-ai-study` repository**.
3. Allow the extracted files to replace the existing files when prompted.
4. Do not delete your local `.git` folder. This ZIP intentionally does not include `.git`.
5. Open `index.html` in a browser and review the page.
6. When satisfied, commit and push the changes to GitHub.

The ZIP paths start at the repository root. Do not extract it into an additional nested `kiwi-ai-study` folder.

## Notes
- Existing book cover and social-channel image assets are retained.
- Existing page copy, navigation labels, privacy page, terms page, and verification TXT file are retained.
- The navigation and content links that were `#` placeholders in the original project remain placeholders; destination pages/URLs have not been invented.
