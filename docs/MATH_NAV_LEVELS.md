# Math navigation levels (Level 1 / Level 2)

Use this naming split everywhere grade hubs, catalogs, and sidebars are maintained.

## Level 1 — Chapter (grade hub)

**What it is:** The large chapter heading on a **grade hub** page (`math/grade-N.html`), e.g. *Number Skills & Operations*, *Functions & Graphs*, *Trigonometry*.

**Must match:** The **Math Foundations** and **Mathematical Thinking** hub cards on:

- `math/math-foundations.html` (seven foundation areas)
- `math/mathematical-thinking.html` (seven thinking areas, aligned with Math Foundations including Trigonometry)

Use the **same English and Chinese strings** as those cards (`data-en` / `data-zh` on each `edu-topic h3`).

**In the catalog:** `data/math-topics.json` → `chapters.<chapter_id>.title_en` / `title_zh`.  
Each topic row points at one chapter via `chapter_id`.

**On the page:** Each chapter card shows an Ontario learning-order badge `01`, `02`, … in `span.kiwi-book-chapter-number` beside bold `p.kiwi-book-chapter-title > strong` inside `nav.kiwi-book-toc` (generated by `local/kiwi_math_catalog.py`). Grade hub pages do **not** show the grade/course pill row under the banner.

**Rule:** Level 1 text is **never** used as the label for an individual lesson link in the grade hub list.

---

## Level 2 — Sidebar hub (grade hub link + sidebar)

**What it is:** The **topic row** under a chapter on the grade hub — the name learners see in the **left sidebar** when they open that topic track (L3 hub or thinking layout).

**Must match:**

- **Math Foundations:** The `h1` on the L3 **category hub** page (`foundation-*.html` banner / `pagefind:title_en` when that page is the sidebar “section” entry), or the sidebar’s current section label — **not** the Level 1 card title alone.
- **Mathematical Thinking:** The sidebar link text on `kiwi-topic-sidebar` / section hub for that track (e.g. *Number Strategies*, *Recovering a Function Rule…*), aligned with the thinking hub card **area** but using the **specific lesson-group title** shown in the sidebar.

**In the catalog:** `topics[].title_en` / `title_zh` — this is what appears in the **numbered list** under each chapter on `grade-N.html` and in **Ontario course code** cards (`by-ontario-course.html`). Course cards list Level 2 only: `list_on_grade_hub: true` **or** Ontario-import rows (`verified_note` starts with `Ontario curriculum expectation alignment`). Nested pages under a hub (e.g. right-triangle splits inside *Trigonometry Fundamentals*) stay out of both UIs.

**Ontario requirement pills (after the topic link):** When `topics[].courses` is non-empty (e.g. `MTH1W`, `MPM2D`, `MCR3U`), the grade hub shows a **course pill** immediately after the Level 2 link in the same list row (`span.kiwi-book-topic-courses`). Elementary-only topics with no secondary course code omit the pill. Lesson pages still use the full grade strip from the catalog injector when labeled.

**Rule:** Level 2 titles must be **distinct from** the Level 1 chapter title in the same row.  
If a page’s `pagefind:title_en` equals the chapter card (Level 1), set an explicit Level 2 title in `local/kiwi_math_topics_data.py` or `local/kiwi_ontario_math_grades.py` (do not rely on auto-import from the L3 banner when it duplicates Level 1).

## Quick reference

| Level | User-facing role | Grade hub UI | Source of truth |
|------:|------------------|--------------|-----------------|
| 1 | Chapter / strand | `p.kiwi-book-chapter-title` (bold body) | `chapters.*` + MF/MT hub cards |
| 2 | Sidebar track / hub | `ol.kiwi-book-topic-list` link (regular body) + optional course pill | `topics[].title_*`, `topics[].courses` |

## Breadcrumbs

Grade hubs keep the trail: **Home › Math Education › Math by Grade › Grade N Mathematics** (`assets/js/drive-breadcrumb.js`).  
Do not remove `drive-breadcrumb.js` from generated grade pages when editing catalog templates.

## Grade hub layout

Generated pages use `body.kiwi-grade-hub`. Each Level 1 chapter is a **card** inside `nav.kiwi-book-toc`:

- **Mobile:** one column of chapter cards.
- **Desktop (768px+):** two columns of chapter cards (`assets/css/styles.css`).

Styling changes for grade hubs should target `.kiwi-grade-hub` so lesson pages are unaffected.

## Topic order on grade hubs (Ontario learning sequence)

Under each Level 1 chapter, topic links sort by `topics[].sort` from **`local/kiwi_ontario_learning_order.py`** (Ontario strand / course progression — not sidebar order). Edit the ordered file lists or trig block there, then regenerate the catalog.

## After changing titles

```powershell
python local/kiwi_math_catalog.py
```

Then hard-refresh the grade hub in the browser.
