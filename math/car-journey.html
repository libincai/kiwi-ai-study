A Car’s Journey

What can a car’s journey teach us about functions? Follow a car as it accelerates, travels at a steady speed, and slows to a stop. One familiar journey reveals three important function types — quadratic, constant, and linear — and shows when an inverse function is possible.

One journey, three stages

Imagine a car travelling along a country road with a speed limit of 90 km/h. It begins at rest, accelerates until it reaches 90 km/h, maintains that speed, and then decelerates to a complete stop.

We will use a simplified mathematical model to describe its speed over 13 seconds.

The journey at a glance

01 · Accelerate0–3 s
0 → 90 km/h
02 · Cruise3–8 s
Stays at 90 km/h
03 · Decelerate8–13 s
90 → 0 km/h

The speed–time function

Let t represent time in seconds and v(t) represent the car’s speed in kilometres per hour. The complete journey is described by a piecewise function: each rule applies only during its own time interval.

v(t) = { 10t²    0 ≤ t ≤ 3
          90       3 < t ≤ 8
          90 − 18(t − 8)   8 < t ≤ 13 }Speed v is measured in km/h; time t is measured in seconds.

A simplified speed–time graph for the complete 13-second journey.

A modelling note
The quadratic rule in Stage 1 is a simplified model for exploring functions and patterns. It does not represent constant physical acceleration. The model is designed to make the three function types easy to compare.

Three stages, three function types

1

Accelerating — Quadratic

v(t) = 10t²,   0 ≤ t ≤ 3

The car’s speed rises from 0 to 90 km/h. Because time is squared, the graph is a curved parabola. The speed increases by larger amounts during each one-second interval.

  • Function type: quadratic
  • Graph: a curved parabola
  • First differences: +10, +30, +50
  • Second differences: +20, +20
2

Cruising — Constant

v(t) = 90,   3 < t ≤ 8

The car maintains 90 km/h. Its speed does not change as time passes, so the graph is a horizontal line and the rate of change is zero.

  • Function type: constant
  • Graph: a horizontal line
  • Rate of change: 0
3

Decelerating — Linear

v(t) = 90 − 18(t − 8)
8 < t ≤ 13

The car slows from 90 km/h to 0 km/h over five seconds. Its speed decreases by 18 km/h every second, so the graph is a straight line sloping downward.

  • Function type: linear
  • Graph: a decreasing straight line
  • Rate of change: −18 km/h per second

Look closer: the quadratic step pattern

During acceleration, v(t) = 10t². At t = 0, 1, 2, and 3 seconds, the speeds are 0, 10, 40, and 90 km/h.

Why do the differences change?

For the basic quadratic function y = t², the first-difference pattern is 1, 3, 5, … . Multiplying the function by 10 multiplies every step by 10.

10 × 1, 10 × 3, 10 × 5
= 10, 30, 50

The second differences are 30 − 10 = 20 and 50 − 30 = 20. Constant second differences are a key sign of a quadratic pattern when the input intervals are equal.

What happens when we reverse the relationship?

The original function takes time as its input and gives speed as its output. An inverse relationship reverses those roles: speed becomes the input, and time becomes the output. It answers a new question: “How long does it take the car to reach this speed?”

Stage 1: the inverse is a function

During acceleration, every speed from 0 to 90 km/h occurs at exactly one time. Starting with v = 10t² and solving for t gives:

t = √(v / 10),   0 ≤ v ≤ 90

For example, a speed of 40 km/h is reached at t = 2 seconds.

Stage 2: the inverse is not a function

The car travels at 90 km/h for the entire interval from just after 3 seconds through 8 seconds. The same speed corresponds to many different times. Reversing the relationship therefore gives more than one time for the input 90 km/h.

The inverse relation is a vertical segment at v = 90. It fails the vertical line test, so it is not an inverse function.

Stage 3: the inverse is a function

During deceleration, each speed between 0 and 90 km/h occurs once. Solve v = 90 − 18(t − 8) for t:

t = 8 + (90 − v) / 18
0 ≤ v < 90

The inverse tells us when the car reaches a particular speed while slowing down.

The key condition: one-to-one

An inverse is a function only when the original function is one-to-one on the domain being considered. The acceleration and deceleration stages each meet this condition. The constant-speed stage does not.

The inverse relationship is a reflection across y = x. But that reflection is not always a function.

The inverse relationship: speed becomes the input

The constant-speed stage becomes a vertical segment: one speed value corresponds to many times, so the inverse relation is not a function.

How does the coefficient change a quadratic graph?

Now compare three simplified quadratic speed models over the same three-second interval. Each starts from zero, but the coefficient a changes how quickly the output grows.

ModelFunctionSpeed at 3 s
Slower increasev = 5t²45 km/h

Faster increasev = 20t²180 km/h

A larger positive coefficient makes the outputs grow more rapidly for the same time values, and the parabola becomes narrower. The 180 km/h result is a mathematical comparison, not a recommendation or a realistic speed for the original 90 km/h road.

THE BIG IDEA

One real-life story. Many mathematical connections.

A car’s journey is more than a speed graph. It gives us a way to connect functions, graphs, domains and ranges, rates of change, differences, coefficients, and inverse relationships. Mathematics becomes easier to understand when we can see how its ideas describe the world around us.
