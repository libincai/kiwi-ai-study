Recovering a Function Rule from Function Notation

Ontario Curriculum Connection

Grade 11 Functions — MCR3U

“Students will reason mathematically and communicate their thinking as they solve multi-step problems.”

— The Ontario Curriculum, Grades 11 and 12: Mathematics, Ontario Ministry of Education, 2007, Functions, Grade 11, University Preparation (MCR3U), page 43.

How This Topic Connects

This activity supports these curriculum goals by developing students' ability to use function notation, apply algebraic substitution, and reason through a multi-step problem to recover a general function rule and evaluate a new input.

Understanding the Idea

We often use function notation to calculate the output of a function when we know its rule and its input.

For example, if we know

f(x)=x2−1f(x) = x^{2} - 1

we can substitute a new expression, such as x+1x + 1 or x2+1x^{2} + 1, into the function to find the corresponding output.

But what if we are given f(x+1)f(x + 1) instead of f(x)f(x)? Can we recover the original function rule? Once we find that rule, can we use it to calculate the output for a completely different input?

These questions develop an important algebraic skill: using substitution and algebraic manipulation to recover a general function rule and then evaluate the function at a new input.

This process involves two key steps:

  1. Recover the general rule: Work backward from the given expression to determine f(x)f(x).

  2. Evaluate the new input: Substitute the entire new input expression into the general rule.

Let's explore how this works.

Example: From f(x+1)f(x + 1) to f(x2+1)f\left( x^{2} + 1 \right)

Suppose we are given

f(x+1)=x2+2xf(x + 1) = x^{2} + 2x

Our goal is to determine

f(x2+1)f\left( x^{2} + 1 \right)

We cannot simply replace x+1x + 1\ with x2+1x^{2} + 1 on the right-hand side. First, we need to recover the general rule f(x)f(x).

Step 1: Recover the General Rule f(x)f(x)

We know that

f(x+1)=x2+2xf(x + 1) = x^{2} + 2x

Notice that the input on the left is x+1x + 1, not just xx.

To recover the general rule, let

u=x+1u = x + 1

Then

x=u−1x = u - 1

Substitute x=u−1x = u - 1 into the given expression:

f(u)=(u−1)2+2(u−1)f(u) = (u - 1)^{2} + 2(u - 1)

Expand and simplify:

f(u)=u2−2u+1+2u−2f(u) = u^{2} - 2u + 1 + 2u - 2
f(u)=u2−1f(u) = u^{2} - 1

Since uu is simply a placeholder for the input, we can write the general rule using xx instead:

f(x)=x2−1\boxed{f(x) = x^{2} - 1}

Step 2: Calculate f(x2+1)f\left( x^{2} + 1 \right)

Now that we know the general rule,

f(x)=x2−1f(x) = x^{2} - 1

we substitute the entire expression x2+1x^{2} + 1 for the input xx.

f(x2+1)=(x2+1)2−1f\left( x^{2} + 1 \right) = \left( x^{2} + 1 \right)^{2} - 1

Expand the square:

f(x2+1)=x4+2x2+1−1f\left( x^{2} + 1 \right) = x^{4} + 2x^{2} + 1 - 1

Simplify:

f(x2+1)=x4+2x2\boxed{f\left( x^{2} + 1 \right) = x^{4} + 2x^{2}}
What Have We Learned?

Knowing f(x+1)f(x + 1) does not mean we have to stop there. We can use algebraic reasoning to recover the general rule f(x)f(x), then use that rule to calculate the output for another input.

The key is to recognize that the expression inside the function notation represents the input. Once the general rule is known, we can substitute a new input expression and follow the same rule.

Recover the rule. Substitute the new input. Simplify the result.
