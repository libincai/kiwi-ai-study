Measures of Center

Measures of center are single values used to describe the “middle” or “typical” value of a set of data. The three main measures are mean, median, and mode.

Example:

Data Set: {2,4,4,5,6,9,10} (already ordered for convenience)

Mean

The mean, commonly called the average, is calculated by adding up all the values in a data set and then dividing the total by the number of values in the set.

Example:

Using the data set {2,4,4,5,6,9,10} (7 values total):

  • Sum: 2+4+4+5+6+9+10=40

  • Mean: 40÷7≈5.71

Median

The median is the middle value of a data set that has been ordered from least to greatest.

  • If there is an odd number of data points, the median is the single middle number.

  • If there is an even number of data points, the median is the average (mean) of the two middle numbers.

Examples:

  • For a odd set {2,4,4,5,6,9,10}:

    • the middle number is 5.

    • the median is 5.

  • For an even set {1,2,3,6,8,9}:

    • the middle two numbers are 3 and 6.

    • the median is (3+6)÷2=4.5(3 + 6) \div 2 = 4.5.

Mode

The mode is the value that appears most frequently in a data set. A set can have one mode, more than one mode, or no mode at all.

Examples:

  • Using the data set {2,4,4,5,6,9,10}:

    • the number 4 appears twice, which is more than any other number.

    • the mode is 4.

  • For {1,2,3,4}:

    • there is no mode.
