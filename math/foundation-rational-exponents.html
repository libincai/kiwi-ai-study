Rational Exponents

A rational exponent can be expressed using a root. When the exponent is a fraction, the denominator indicates the root to take, while the numerator indicates the power to apply.

For example,

x1n=xnx^{\frac{1}{n}} = \sqrt[n]{x}

and

xmn=xmnx^{\frac{m}{n}} = \sqrt[n]{x^{m}}

Here, n≠0n \neq 0 because the denominator of a fraction cannot be zero.

For easy remembering:

xmn=(xm)1n=xmnx^{\frac{m}{n}} = {(x^{m})}^{\frac{1}{n}} = \sqrt[n]{x^{m}}
xmn=(x1n)m=(xn)mx^{\frac{m}{n}} = {(x^{\frac{1}{n}})}^{m} = \left( \sqrt[n]{x} \right)^{m}
💡Is “A rational exponent is connected to the root function” correct?

This statement is only partially correct. A rational exponent can represent a root when the exponent is a fraction, but an integer exponent does not necessarily represent a root. For example, x2x^{2} represents a power, not a root.

A more precise statement is: “A rational exponent written as a fraction can represent a root and a power.”

Concepts: Roots and Radicals

A root reverses the action of raising a number to a power. For example, because 4³=644^{3}\ = \ 64, the cube root of 64 is 4.

In general, if yⁿ=xy^{n}\ = \ x, then yy is an nth root of xx. Here, nn is a whole number greater than 1, and xx and yy are real numbers.

Since 36=62=(−6)236 = 6^{2} = (-6)^{2}, both 6 and −6 square to give 36.

The principal root

The radical symbol x\sqrt{\vphantom{1}} is used to represent roots. The principal nnth root of xx is written as xn\sqrt[n]{x}, where nn is the index and xx is the radicand.

The principal root is the real nnth root of xx. For an even index, the principal root is non-negative; for an odd index, it has the same sign as xx. If no index is shown, the index is understood to be 22.

Even and odd indices

💡Learning Insight
A negative number does not have a real even root. For example, −36\sqrt{- 36} is not a real number. A positive number can have two real even roots, but the radical symbol x\sqrt{\vphantom{1}} gives the non-negative principal root: 36=6\sqrt{36} = 6.
Simply Method to Evaluate
  • For an even numerator: When the base is negative and the root is real, an even power makes the result positive, so the negative sign can be removed after converting to radical form. For example:
    (−8)23=823=83(-8)^{\frac{2}{3}} = 8^{\frac{2}{3}} = \sqrt[3]{8}
  • For an odd numerator: When the base is negative and the root is real, move the negative sign outside the radical instead of keeping it inside the radicand. For example:
    (−8)13=−83(-8)^{\frac{1}{3}} = - \sqrt[3]{8}
  • For a negative exponent: First, rewrite the expression using the reciprocal of the base and make the exponent positive.
Initial Value

When an exponential function starts with an initial value other than 11, multiply the exponential expression by that initial value.

f(x)=a⋅cx\boxed{f(x) = a \cdot c^{x}}

Here, aa represents the initial value, and cc is the growth or decay factor.

The basic form of an exponential function is

f(x)=cxf(x) = c^{x}

where c>0c > 0 and c≠1c \neq 1.

  • Exponential growth: When c>1c > 1, the function increases as xx increases.
  • Exponential decay: When 0<c<10 < c < 1, the function decreases as xx increases.
Transformation

General equation for transformations

A transformed function can be written in the form

y=af(b(x−h))+k\boxed{y = af\left( b(x - h) \right) + k}

Each parameter controls a different transformation:

  • aa: Vertical transformation — stretches or compresses the graph vertically. If a<0a < 0, the graph is also reflected across the x-axis.
  • bb: Horizontal transformation — stretches or compresses the graph horizontally. If b<0b < 0, the graph is also reflected across the y-axis.
  • hh: Horizontal translation — shifts the graph right when h>0h > 0 and left when h<0h < 0.
  • kk: Vertical translation — shifts the graph up when k>0k > 0 and down when k<0k < 0.

Applying the formula to an exponential function

For the original exponential function y=cxy = c^{x}, the transformed equation becomes

y=a⋅cb(x−h)+k\boxed{y = a \cdot c^{b(x - h)} + k}

Here, c>0c > 0 and c≠1c \neq 1. The parameters aa, bb, hh, and kk determine how the original graph changes.
