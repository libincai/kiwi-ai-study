Linear vs. Non-linear Functions

Functions can be classified by their algebraic form, degree, and graph shape. Three useful types to compare are linear, quadratic, and constant functions.

Linear Function

A linear function has the form

f(x)=mx+b,m≠0f(x)\ = \ mx\ + \ b,\ \ m\ \neq \ 0

  • Degree: 1.

  • Table: For equally spaced xx-values, the first differences are constant.

  • Graph: A sloping straight line.

Quadratic Function

A quadratic function has the form

f(x)=ax2+bx+c,a≠0f(x) = \ ax^{2}\ + \ bx\ + \ c,\ \ a\ \neq \ 0

  • Degree: 2.

  • Table: For equally spaced xx-values, the first differences change, but the second differences are constant and non-zero.

  • Graph: A parabola (U-shape or inverted U-shape).

For example, for f(x)=x²f(x)\ = \ x², when xx increases by 1, the second differences are

Δ²y=2\Delta ²\ y\ = \ 2

Constant Function

A constant function has the form

f(x)=cf(x)\ = \ c

Its output does not change as xx changes.

  • Rate of change: 0.

  • Graph: A horizontal straight line.

  • Degree: 0 if c≠0c\ \neq \ 0; undefined if c=0c\ = \ 0.

💡Learning Insight

The Zero Polynomial is

f(x)=0f(x)\ = \ 0

It is a constant function because its output is always zero. However, its degree is undefined under the standard convention.

For a non-zero constant polynomial, such as f(x) = 5, the degree is 0.

Remember: The zero polynomial is still a constant function, even though its degree is undefined.
