Mental Squaring and Square Rooting

Squaring and rooting numbers doesn’t always require long multiplication or calculators. By identifying specific number ranges, we can use unique patterns to calculate results instantly.

The Split-Digit Method: Most mental tricks involve calculating the first two digits and the last two digits separately, then joining them together.

Range-Specific Shortcuts:

Squaring (90s): For a number 90+𝑛, the first two digits are 80+2𝑛 and the last two are (10−𝑛)2.

Example:

922→ (80+2×2) ‖ (10−2)2=8464.

Hint: For mnemonics, 10−𝑛 can be called 𝑛’s 10-friend.

The 10-Friend: For any digit 𝑛, its “10-friend” is defined as the value 10−𝑛. These are pairs of numbers that sum exactly to 10 (e.g., 2 and 8 are 10-friends).

Square Rooting (Inverse): Reverse the process by identifying the boundary hundreds and the “10-friend” of the last digit.

Example:

For √8464, it lies between 902(8100) and 1002(10000). Since it ends in 4, the root ends in 2 or its 10-friend 8. Given the proximity to 8100, the answer is 92.

Special Cases: Numbers ending in 5 or those between 11–19 have their own “fast-track” rules that can be similarly inverted for quick rooting.

Square Rooting Numbers Ending in 25

If a number ends in 25, you can find its square root mentally by reversing the “Squaring Numbers Ending in 5” rule.

The method

To find N\sqrt{N}, where NN is a perfect square ending in 25:

  1. Identify the suffix: The last two digits are 25, so the square root ends in 5.

  2. Find the prefix: Remove the last two digits to obtain XX. Find two consecutive whole numbers, aa and a+1a + 1, whose product is XX.

  3. Combine: The square root is the number aa followed by 5.

Examples:

625\sqrt{625}

  • Remove 25: X=6X = 6.

  • Find consecutive numbers: 2×3=62 \times 3 = 6.

  • Append 5 to 2: 625=25\boxed{\sqrt{625} = 25} .

2025\sqrt{2025}

  • Remove 25: X=20X = 20.

  • Find consecutive numbers: 4×5=204 \times 5 = 20.

  • Append 5 to 4: 2025=45\boxed{\sqrt{2025} = 45} .

Why it works

A number ending in 5 can be written as 10a+510a + 5. Squaring it gives

(10a+5)2=100a(a+1)+25.(10a + 5)^{2} = 100a(a + 1) + 25.

Therefore, the digits before 25 represent a(a+1)a(a + 1), the product of two consecutive whole numbers.

Squaring Numbers Near 50 (Specific Strategies)

These strategies use the last digit of the number to find the result instantly. They focus on the “Last Digit” (𝑥).

The 40s range

Let the number be 40+x40 + x, where xx is the last digit (x=1,2,…,9x = 1,2,\ldots,9).

  • First two digits: 15+x15 + x

  • Last two digits: (10−x)2(10 - x)^{2}

Examples:

422

Since 42=40+242 = 40 + 2, we have x=2x = 2.

  • First part: 15+2=1715 + 2 = 17

  • Last part: (10−2)2=64(10 - 2)^{2} = 64

  • Combine: 422=1,764\boxed{42^{2} = 1,764}

472

Since 47=40+747 = 40 + 7, we have x=7x = 7.

  • First part: 15+7=2215 + 7 = 22

  • Last part: (10−7)2=09(10 - 7)^{2} = 09 (must keep two digits)

  • Combine: 472=2,209\boxed{47^{2} = 2,209}

Why 15?

(40+x)2=1600+80x+x2(40 + x)^{2} = 1600 + 80x + x^{2}

We want to express the square as a number of hundreds plus a two-digit remainder:

(40+x)2=1600+80x+x2=1600+100x−20x+x2=1500+100x+100−20x+x2=100(15+x)+(10−x)2\begin{aligned} (40 + x)^{2} & = 1600 + 80x + x^{2} \\ & = 1600 + 100x - 20x + x^{2} \\ & = 1500 + 100x + 100 - 20x + x^{2} \\ & = 100(15 + x) + (10 - x)^{2} \end{aligned}

(50+x)2=2500+100x+x2(50 + x)^{2} = 2500 + 100x + x^{2}

Squaring Numbers Near 50 (Generic Strategy)

For numbers near 50, we can express the value as 50±𝑑. This generic strategy focuses on the “Distance from 50” (𝑑). The result is a four-digit number where:

  1. First two digits =25±d25 \pm d

  2. Last two digits =𝑑2

Numbers below 50

For numbers in the 40s, calculate how far the number is below 50. This distance, dd, determines both parts of the result.

The Distance from 50 Rule:

(50−d)2=(25−d)×100+d2\boxed{(50 - d)^{2} = (25 - d) \times 100 + d^{2}}

  • First part: 25−d25 - d

  • Last part: d2d^{2}, written using exactly two digits.

Examples:

432

  • Distance: d=7d = 7, since 50−7=4350 - 7 = 43.

  • First part: 25−7=1825 - 7 = 18

  • Last part: 72=497^{2} = 49

  • Combine: 432=1,84943^{2} = 1,849

482

  • Distance: d=2d = 2, since 50−2=4850 - 2 = 48.

  • First part: 25−2=2325 - 2 = 23

  • Last part: 22=042^{2} = 04 (must keep two digits)

  • Combine: 482=2,30448^{2} = 2,304

Numbers Above 50

For numbers in the 50s, calculate how far the number is above 50. Add this distance, dd, to 25 to find the first part.

The Distance from 50 Rule:

(50+d)2=(25+d)×100+d2\boxed{(50 + d)^{2} = (25 + d) \times 100 + d^{2}}

  • First part: 25+d25 + d

  • Last part: d2d^{2}, written using exactly two digits.

Examples:

532

  • Distance: d=3d = 3, since 50+3=5350 + 3 = 53.

  • First part: 25+3=2825 + 3 = 28

  • Last part: 32=093^{2} = 09 (must keep two digits)

  • Combine: 532=2,80953^{2} = 2,809

592

  • Distance: d=9d = 9, since 50+9=5950 + 9 = 59.

  • First part: 25+9=3425 + 9 = 34

  • Last part: 92=819^{2} = 81

  • Combine: 592=3,48159^{2} = 3,481

💡Learning Insight
Find the distance from 50, subtract it from 25 for numbers below 50, or add it to 25 for numbers above 50. Then append the two-digit square of the distance.
Square Rooting Numbers Near 50

The 40s range

For perfect squares between 402=1,60040^{2} = 1,600 and 502=2,50050^{2} = 2,500, we can find the square root using the last two digits.

The Strategy

  1. Check the range: Confirm that the number is between 1,600 and 2,500.

  2. Find the distance: Take the square root of the last two digits to find dd.

  3. Subtract from 50: The square root is 50−d50 - d.

Example:

2116\sqrt{2116}

  • The last two digits are 1616.

  • Since 16=4\sqrt{16} = 4, the distance is d=4d = 4.

  • Calculate 50−4=4650 - 4 = 46.

Therefore,

2116=46\boxed{\sqrt{2116} = 46}

To square a number in the 90s, let nn be the last digit. For example, for 96, n=6n = 6.

  1. First two digits: Calculate 80+2n80 + 2n.

  2. Last two digits: Calculate (10−n)2(10 - n)^{2}. Use a leading zero if needed.

Example:

  • First part: 80+2(6)=9280 + 2(6) = 92

Square Rooting: The 90s Range

For perfect squares between 902=8,10090^{2} = 8,100 and 1002=10,000100^{2} = 10,000, we can find the square root using the last two digits.

The Strategy

  1. Check the range: Confirm that the number is between 8,100 and 10,000.

  2. Find the distance: Take the square root of the last two digits to find dd. This gives the distance from the square root to 100.

  3. Subtract from 100: The square root is 100−d100 - d.

Example:

8281\sqrt{8281}

  • The last two digits are 81.

  • Since 81=9\sqrt{81} = 9, we have d=9d = 9.

  • Calculate 100−9=91100 - 9 = 91.

Therefore,

8281=91\boxed{\sqrt{8281} = 91}
Square Rooting Numbers Between 𝟏𝟎 𝟐 \mathbf{10}^{\mathbf{2}} and 𝟏𝟎𝟎 𝟐 \mathbf{100}^{\mathbf{2}}

For a perfect square NN between 100100\ and 10,00010,000, you can find its square root mentally by identifying its tens digit first, then its units digit.

The Strategy

Find the tens digit

You can estimate a square root without a calculator by using perfect squares and comparing the number with nearby benchmark squares.

Find two consecutive multiples of 10 whose squares surround the given number. The tens digit of the square root is the smaller multiple of 10 divided by 10.

(10a)2<N<[10(a+1)]2(10a)^{2} < N < \left\lbrack 10(a + 1) \right\rbrack^{2}

The tens digit of N\sqrt{N} is aa.

For example, to find 5329\sqrt{5329}:

Since 702=490070^{2} = 4900 and 802=640080^{2} = 6400, we know that

70<5329<8070 < \sqrt{5329} < 80

The tens digit of 5329\sqrt{5329} is 7.

Find the units digit

Look at the last digit of the number under the square root. The last digits of perfect squares follow a pattern that helps identify the possible units digits.

  1. If the number ends in 25, use the Square Rooting Numbers Ending in 25 shortcut.

  2. Otherwise, identify the possible units digits using the last-digit pattern. Then compare the number with the benchmark squares to decide which units digit is more likely. If the number has more than three digits, simplify the comparison by moving the decimal point two places to the left.

Examples:

5329\sqrt{5329}

  1. Find the tens digit. Since

702=4900<5329<6400=80270^{2} = 4900 < 5329 < {6400 = 80}^{2},

the tens digit is 7.

  1. Find the possible units digits. The last digit of 5329 is 9. Since 3² and 7² end in 9, the square root could be 73 or 77.

  2. Choose the units digit. Simplify by moving the decimal, 53.29 compared with 49 and 64. 53.29 is closer to 49, so the square root is closer to 70 than to 80. Therefore, we choose 73.

Final answer: 5329=73\sqrt{5329} = 73. It's a simple trick that mixes number patterns and a bit of comparison.

361\sqrt{361}

  1. Since 102=100<361<400=20210^{2} = 100 < 361 < {400 = 20}^{2}, the tens digit is 1.

  2. The last digit of 361 is 1. Since 1² and 9² end in 1, the square root could be 11 or 19.

  3. Since 361 is easy to compare with 100 and 400, we don’t need to move decimal. 361 is closer to 400 than to 100. Therefore, we choose 19.

Final answer: 361=19\sqrt{361} = 19.

💡Learning Insight
First find the tens digit using the bounding squares. Then use the last digit of N and comparing to determine the units digit.
