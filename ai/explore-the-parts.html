AI FOUNDATIONS · HOW AI WORKS

Explore the Parts Behind AI

AI tools may look simple on screen, but several parts work together behind the scenes. Understanding them helps you use AI thoughtfully.

Think of an AI assistant as a small team

A model processes information and generates outputs. Knowledge sources provide reference material. Context helps the system understand the situation. Memory may retain selected information. Tools let AI retrieve information or perform actions.

🧠

Model

The engine that processes input and produces an answer.

📚

Knowledge and context

Reference information and details relevant to this conversation.

🗂️

Memory and tools

Memory can retain useful details; tools can help complete tasks.

Try it yourself

When an assistant answers using an uploaded document, identify the model, reference knowledge, prompt context and any tools involved.

Key takeaway

AI is a system of cooperating components. The exact parts differ by product; memory and tool access are not always enabled.
